Small Business Loan Predictor

Machine learning · SBA loan outcomes · Streamlit

About the Project

I built a machine learning system to predict the outcome of small-business loan applications using 899K+ records from the U.S. Small Business Administration (SBA). The project focused on transforming a large, real-world dataset into a usable predictive model while addressing challenges such as missing data, categorical features, and class imbalance. I developed an end-to-end Scikit-learn pipeline, evaluated multiple classification approaches, and deployed the final model as an interactive Streamlit application.

Key Work

  • Processed and analyzed 899K+ SBA loan records to identify patterns associated with loan outcomes.
  • Performed data cleaning, preprocessing, and feature engineering on large-scale tabular data.
  • Developed and evaluated multiple classification models using Scikit-learn.
  • Applied class-imbalance mitigation to improve performance across minority and majority outcomes.
  • Compared model performance using appropriate evaluation metrics rather than relying solely on accuracy.
  • Deployed the trained model through Streamlit, allowing users to interact with the prediction system.
