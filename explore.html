Tech in 100 Words or Less

Short explanations of interesting technologies, concepts, and ideas I'm learning about. Finding the answer when curiosity takes over.

What is RAG?

Imagine asking an AI assistant a question about your project notes. Retrieval Augmented Generation (RAG) lets it search those notes and use relevant passages when writing an answer. This gives the model information beyond its training data, without retraining it every time a document changes. It can also include sources, making the answer easier to check. The quality still depends on what the search finds and how the model uses it. RAG is useful when you want answers grounded in a particular collection of information, such as research papers, company documents, or your own files.

Why are vector databases useful?

You might search for “fix a leaking tap” and find a guide titled “faucet repair.” A vector database helps make that connection. It stores embeddings: lists of numbers that represent features of text, images, or other data. An embedding model places related items near one another, and the database searches for those nearby matches. This is useful when people describe the same thing in different words. It supports document search, recommendations, and finding similar images. Results depend on the embedding model and the data, so a close match still needs to be checked for relevance.

What is an MCP server?

An AI assistant becomes more useful when it can work with the tools you already use. An MCP server provides a connection through the Model Context Protocol. It can make tools, data, and reusable prompts available to a compatible AI application. For example, a server could let an assistant search project files or look up information in a database. The application decides which capabilities to use, within its permissions. Having a shared protocol makes integrations easier to reuse, though each application may support different features. The server supplies access; the AI application handles the conversation.
